# WE:GREEN

지역 조경업체 디렉토리 프론트엔드 MVP (Sprint Mission 6).

## 핵심 기능

1. **업체 목록 조회 + 필터** — 지역/전문 분야 필터, empty state
2. **업체 상세 보기** — Mock + 사용자 등록 데이터
3. **업체 등록** — 폼 검증 후 localStorage 저장, 새로고침 유지
4. **로그인 시뮬레이션** — localStorage 기반 인증 흐름

## 기술 스택

- React + TypeScript (interface 기반 타입)
- React Router
- Vite
- localStorage / Mock Data

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```
